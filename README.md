## Project Overview
Developed during a summer research internship at California State University, Monterey Bay (CSUMB), this project demonstrates a proof-of-concept agricultural robotics system designed to reduce physical strain on farmworkers and improve harvesting efficiency. By combining a **Universal Robots collaborative robot (cobot)** with **NVIDIA Jetson edge AI**, the system identifies fruit ripeness, detects surface defects, and automates sorting in real time.

## My Contributions
* **Computer Vision & Model Training:** Built and trained a real-time object detection model using custom labeled datasets (60 images; 80/20 train-validation split) to accurately classify apples, oranges, and strawberries on an edge AI accelerator.
* **Data Pipeline & Annotation:** Collected, annotated, and structured training images using **MakeSense AI** and **COCO format**, establishing standardized, controlled imaging conditions to improve detection reliability.
* **Model Optimization & Hardware Calibration:** Resolved real-world detection edge cases—including false positives from leaves and stems and low confidence at varied angles—by refining dataset consistency and calibrating the positioning of the **Gemini 335L** depth camera.

## Technical Stack
* **Hardware:** Universal Robots Cobot, NVIDIA Jetson Orin AGX (64GB) AI Accelerator, Custom 3D-Printed End-Effector
* **Software & Frameworks:** PolyScope X, URScript, MakeSense AI (Image Annotation & Labeling)
* **Skills:** Computer Vision, Edge AI Deployment, Robotic Kinematics, Rapid Prototyping (CAD / 3D Printing)
